欢迎来到 Web 开发系列教程！这里是第一部的目录页。

每天你打开手机、电脑，看到的大部分东西都和 Web 有关：新闻页面、购物网站、公司官网、在线文档、后台管理系统，甚至很多手机 App 里嵌着的界面，底层也是网页技术。浏览器早就不只是“看网页的工具”，它更像一个万能的操作系统——只要有屏幕、有网络，Web 就能把信息送到人面前。

自 1989 年万维网核心构想提出至今，已经过去三十七年。从早期只能像陈列柜一样展示信息的静态 HTML 页面，到论坛、博客、社交媒体的兴起，再到今天与物联网和在线服务深度融合，Web 的应用领域和体系外延仍在不断扩展。据文中引用资料，2023 年中国数字经济规模达到 53.9 万亿元，对 GDP 增长的贡献率达到 66.45%。Web 早已不是经济中的一个“部门”，而是渗透进几乎所有部门的基础介质：在农业端，数智系统让浇水施肥由数据驱动；在流通端，电商平台通过整合订单与行为数据，把生产端与消费端直接匹配，在全国范围内优化仓储与运输配置。Web 降低了连接成本、压缩了匹配摩擦，使传统产业获得“放大、叠加、倍增”的效率提升。{% ref xzdw-2024 %}

在生活层面，这种嵌入更为细密。支付、政务、社交、医疗挂号、交通出行，都越来越依赖 Web 连接与数字系统。联合国新闻网站的一篇报道有个说法很到位：“数字系统已经如此深入地融入我们的生活，以至于我们几乎注意不到它们——直到它们失效。”（中文为作者译）{% ref un-2026 %}Web 的“重要作用”之所以难以被完整列举，正是因为它的成功之处在于变得不可见：它成了水、电之外的另一层默认基础设施，只不过这一层承载的是协调与信息，而非物质或能量本身。

倘若哪天 Web 大面积失效……通信与支付将中断，医疗系统将停摆，金融与供应链将受阻，经济损失更难以估量。更重要的是，社会对数字系统的依赖日益加深，却未能保持足够的模拟技能和离线备用方案；当大型数字系统出现故障时，“离线替代方案往往已不再可用”。这意味着，Web 失效的严重性不仅来自数字系统本身的重要性，还来自退出数字系统之后的无处可退——纸质流程、人工调度、现金交易、线下协调等能力，在效率逻辑下已被大幅裁撤。{% ref itu-2026 %}灾难来临时，人类未必能及时找到替代方案。说了这么多，其实就一句：Web 对现代社会很重要，值得认真学一学。

这几年变化很快，AI 能写代码、能生成页面，工具也越来越多。但越是这样，越值得把 Web 的基础弄明白：知道自己想要什么效果、知道一段代码为什么这样写、知道出了问题该去哪里找，这些判断力不会因为工具变强而贬值，反而会变得更值钱。Web 也依然是普通人最容易接触、最容易做出东西的技术之一——静态页面阶段几乎不需要配置复杂开发环境，也不必安装庞大的 SDK；它不像 Python、C、Java 那样有较高的入门门槛，也不需要昂贵设备。一个浏览器、一个编辑器，就能开始。

开设这个系列，是因为在 AI 工具日益普及的当下，Web 的作用举足轻重，而很多人并不清楚怎么利用它：有人想少走弯路，有人想提高效率，有人想多一块求职敲门砖，有人想让个人数字资产更自主，也有人只是想把自己的兴趣和想法实现出来。另一方面，中小学信息技术课长期不够受重视，手机又太早、太全面普及，结果不少年轻人能刷一整天手机，却不太会熟练使用计算机，更别说 Web 开发了。不少家长早早让孩子学编程，这本身没错，但如果只盯着“抢跑”，忽略兴趣和成就感，孩子容易还没入门就先累了；这个圈子的入口也会越来越挤，良性竞争反而被破坏。学 Web 不一定非要跟别人挤同一条赛道，学习过程本身也能练系统思维和调试能力。

很多人想学 Web，却被几件事劝退：资料太散、术语太多、路线图太吓人，或者一上来就被要求“先学完一整套体系”。这个系列想换一种走法——**从能看见的东西开始，一步一步来，不急着堆概念**。你会先做出一个能打开的页面，再让它变好看、变好用，然后才慢慢接触更复杂的工具和后端。每一部分都有明确的小目标，学完就能拿出一个像样的东西。

整个系列大致分五部：

- **第一部：页面结构与样式基础。** 从零做出静态页面，理解内容怎么组织、样式怎么生效、布局怎么排、手机和电脑上怎么都好看。这一部不碰复杂的编程逻辑，重点是把手感和判断力练出来。
- **第二部：JavaScript 与浏览器交互。** 让页面“活”起来：按钮能点、表单能校验、数据能请求、状态能保存。
- **第三部：TypeScript、Vite 与 React。** 进入现代前端开发方式，学会用类型、组件和工具来组织更大的项目。
- **第四部：Vue、模板渲染与后端衔接。** 看看另一套框架思路，理解页面在服务端怎么生成，前端怎么和后端 API 打交道。
- **第五部：生产构建、质量保障与项目维护。** 把项目从“能跑”做到“能上线、能维护”：构建、检查、测试、部署、长期迭代。

如果你现在看技术术语还一脸问号，也没关系，一步步跟着走，自然会懂。在这个系列里，你能学到的不只是语法和 API。更重要的是几样更底层的东西：**怎么查文档、怎么读报错、怎么把一个模糊的想法拆成可以动手的小步骤、怎么判断一段代码该不该信**。这些能力在学完任何一个框架之后都还用得上。

你不必记住所有东西。HTML 的标签、CSS 的属性、JavaScript 的方法，都是“用得多了自然就熟”的技能；查得到、改得动，比背得全更重要。这个系列会尽量把“为什么”讲清楚，让你在需要的时候知道去哪里找答案。

如果你已经准备好，我们就从第零章开始：先把工具装好，把学习方式聊明白，然后写下第一个网页。

欢迎启程。
