## 自我介绍

大家好！我是 Slfftz2011 ，目前是杭州的一位中学生，热衷于小项目、游戏开发与 Minecraft 。

我目前有系统性学习过 Python 、 C++ 等编程语言，自学 Java 、 Vue 和其他 Web 技术栈。

自2025年8月14日加入Github截至今日，本人共在Github创建了28个开源仓库（不包含删除的仓库），提交855次，添加星标62个，独立开发绝大多数项目，其中既有代表性的是：

 + 纯Web小游戏：[Cookies.vs.Zombies](https://github.com/slfftz2011/Cookies.vs.Zombies)

    HTML/JavaScript/CSS Web三件套开发的挂机、点击玩法小游戏，部署在 Github Pages ，使用 Pake/Capacitor 打包为桌面端与移动端APP

 + Vue：[IbuprofenLoader](https://github.com/slfftz2011/Ibuprofen-Loader)

    一款现代化的网易我的世界组件加载器，使用 Rust + Vue 3 + TypeScript 技术栈，短期内不考虑继续维护该项目

 + Fabric Mod：[Elements](https://github.com/slfftz2011/elements-fabric-1.20.1)

    一款适用于Fabric 1.20.1的科技类Mod，梦开始的地方，不定期维护

与此同时本人还是 Minecraft 10年铁粉，喜欢原版生存/极限挑战/硬核玩法/养老冒险/简单生电/PvP/游戏底层研究与数据包开发。

网易版与国际版均有活跃。

当前正在开发的数据包为 [Age](https://github.com/slfftz2011/Age) ，硬核生存玩法，欢迎品尝：[前往Modrinth下载](https://modrinth.com/datapack/age-slfftz2011)

我开设本站，是想把我在生活中与开发过程中所遇到的趣事分享出来，将做这些事的过程记录下来：怎么从一个想法变成能跑的东西，踩了什么坑，又是如何解决的。如果你有同样的想法，想必会有帮助。

## 博客定位

在本站中，我想写很多：

我想写一些技术性内容，例如开发经验、一些编程教程，以供众人参考和小白学习；

我想写一些学习笔记，分享的过程同样也是复盘的过程；

我想写一些思考随笔，把脑海中那些对各行业，社会，生活，热点实时的观察与见解留在这儿；

我想好好介绍我所开发的项目，如何实现，有什么用又是如何使用的；

我想写杂谈，发声。

这就是我想写的，更是我要写的。
